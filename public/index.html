Instant boot

Starts from a snapshot of an already-booted system, so you land at a live shell in seconds — not a cold boot.

Actually Linux

A genuine kernel and Ubuntu userspace. apt, bash, Python, real filesystem — do Linux things, for real.

Private by default

Everything runs in your browser. Networking stays off until you flip it on — nothing leaves your machine unless you say so.

Saves your work

Give an instance a name and it keeps its whole disk between visits — installed packages and files come back exactly as you left them.

Optional networking

Turn on real internet per instance — DNS, TCP, HTTPS — when you need to fetch or install something. Off by default, one toggle away.

Many instances

Spin up as many little machines as you like — a scratchpad, a project box, something to break — each independent, each yours.

How it works

3

Do your thing

Run commands, edit files, optionally go online. Name the instance and it all persists for next time.

Ready when you are.

No account, no download, no VM to configure. Just a real Ubuntu machine, one click away.
